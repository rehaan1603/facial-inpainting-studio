# Repository checkpoint

This repository preserves the implementation and research record through **10 October 2026**. It includes the local browser application, inference/evaluation scripts, configuration examples, environment locks, protocols, measured results and navigation indexes. Existing repository visibility/access settings are retained.

Source datasets, uploaded faces, reference photos, generated face images, downloaded generative/reference-model weights, Python environments, local path configuration and delivery ZIP archives stay on the original laptop. Detailed experiment CSV/JSON/JSONL records, audit manifests, plots without photographs, and all twenty-four project-trained best/latest mask-refiner checkpoint files are included. The repository therefore does not run inference from a fresh clone until the documented environments, permitted models, datasets and local configuration are restored. The trained refiner files include optimizer state in latest.pt where recorded, allowing the same training to resume after restoring the environment and permitted data.

Start the configured application with Start Studio.cmd at http://127.0.0.1:8765/. It reuses a running process. The updated testing build currently runs at http://127.0.0.1:8766/; a laptop restart lets Start Studio load current code on 8765. The launcher keeps the server running independently after its window closes. The GPU service binds to loopback and requires the configured laptop.

The reference-photo feature uses existing pretrained methods. Earlier measured experiments, unfinished comparisons and publication requirements are distinguished in research/PROJECT_STATUS.md. Research results are not claims of accepted publication or verified hidden-face recovery. Third-party data, code and weights retain their own terms; see research/DATA_AND_LICENSES.md.

The earlier supplemental inventory is in research/REPOSITORY_ARTIFACT_INVENTORY.json. New [release evidence](research/releases/2026-10-10/README.md) records photo-free per-output metrics, source/output hashes and targeted verification. Dataset identity labels and older local source paths remain traceability metadata. Failed, partial and prepared-only experiments retain their status. The separate Human Faces pilot is labelled apart from the main CelebA evidence.
