# Regional fusion — not implemented in this cycle

The first cycle implements reference selection only. Existing FaceID conditioning uses global recognition embeddings. There is no trainable regional fusion adapter, spatial reference correspondence, cross-attention alignment loss or locally trained restoration generator.

The next decision depends on the selection comparison, including its failures. A regional fusion proposal should specify correspondence under pose/expression changes, actual reference visibility estimation, spatial feature extraction, a bounded training budget and disjoint development identities. It must retain the frozen final split and compare equal-information-budget controls before making contribution claims.

Do not describe the current selector as learned fusion, a novel backbone or proven unknown-person reconstruction.
