# Structure-only reference transport: prospective diagnostic

Specified 28 September 2026 after the history/baseline audit and primary-source review, before implementation or candidate generation. This is a small structural feasibility experiment, **not an established novel method**. No large experiment, training, website promotion or final evaluation follows automatically.

1. **Hypothesis.** Personal references contain local shape information missing from the ResShift scaffold. Moving synthesized structures toward reference landmarks may improve identity and geometry without increasing missing-region or perceptual error.
2. **Motivation.** The completed RefFace baseline shows misplaced/blurred eyes, noses and mouths. Its pooled reference textures do not directly specify reference geometry. Earlier routing/blending/correction screens did not isolate geometric coordinates. Component texture suppression is not a proven cause and will not be changed here.
3. **Mechanism.** Start with frozen ResShift images at seeds 17/29. Extract 68 landmarks from the cached InsightFace 3D68 model, using only x/y (not 3D pose normalization). Target cropping uses the scaffold detector; target landmark extraction receives the observation with missing RGB replaced by 128. Fit each reference to observed target anchors using a 2D similarity transform. Only predicted target landmarks at least eight pixels from damage and image edges are eligible; require six nondegenerate anchors. Never use predicted missing landmarks as registration anchors. Take the coordinatewise median of the four registered shapes. For source/destination landmarks inside the same connected missing region, solve an inverse displacement field: squared bilinear landmark residuals plus 0.05 times discrete Dirichlet energy, with zero displacement outside the mask. Inverse-sample scaffold RGB and restore original visible bytes exactly. References contribute coordinates only: no reference texture, pixel, embedding or latent transfer. No weights are trained.
4. **Possible increment.** Only controlled evidence that personal geometry helps independently of texture could motivate a future contribution. This screen combines established tools; even a positive result would require a stronger novelty distinction before a large study.
5. **Prior art.** [Mo et al. 2004](https://bmva-archive.org.uk/bmvc/2004/papers/paper_129.pdf) already extrapolate shape from visible regions and warp landmarks. [r-FACE](https://arxiv.org/abs/2006.02051) transfers component shape; [3DFaceFill](https://arxiv.org/abs/2110.10395) uses explicit geometry; [RefFaceInpainting](https://arxiv.org/abs/2303.07014) controls identity/texture; [ReSem-Face](https://arxiv.org/abs/2608.04820) uses multi-reference semantic completion. See the dated prior-art audit.
6. **Difference tested.** Transport coordinates of a fixed modern scaffold using personal reference geometry only, pinning visible pixels. The intervention does not modify masks, blend results, route global features, or inject VAE features. Single-reference and wrong-person controls isolate consensus and personal information. We do not claim landmark warping is new.
7. **Failure modes.** Damaged-input landmark hallucination, 2D pose/expression misregistration, incompatible median expressions, insufficient anchors, folds and interpolation blur. Reject failed detection, degenerate registration, no admissible constraints, nonfinite solves, displacement above 10% of width or any nonpositive inverse-map Jacobian in changed masked pixels. Retain every failed row without silent fallback or parameter retry. A warp cannot create absent teeth or infer true hidden gaze; 68 landmarks contain no pupils. Zero displacement must preserve scaffold bytes exactly.
8. **Frozen screen.** Existing identities 1306/2790/1043/787, original four references and removal masks, seeds 17/29. Three structural arms produce at most 24 new transformed images, alongside 40 reused control slots: 64 rows. No new neural generation or identities. Deterministic controls repeated in seed slots are not independent samples. Read clean targets only in separate evaluation after candidate attempts finish.
9. **Controls/metrics.** Compare four-reference geometry, single-reference0 geometry and cyclic wrong-person geometry with unchanged ResShift, corrected reference/context cascade, plain reference cascade, dedicated RefFace ref0 and damaged observation. All reconstructed controls preserve visible pixels. Evaluate FaceNet target/gallery, diagnostic ArcFace, hole/visible MAE, LPIPS, SSIM, PSNR, NIQE, BRISQUE, detection coverage, exact preservation and failures. Add separate 106-landmark regression: output-to-target distance on landmarks whose target locations fall inside damage, normalized by target detector interocular distance, without output alignment. It is a learned proxy, not anatomical truth. Retain missing scores and denominators. Review all identity/seed sheets for gaze, eyelids, spacing, nose, lips, teeth, mouth state, expression, skin and asymmetry; no fabricated human judgments.
10. **Gate.** Freeze protocol and source hashes before generation. Both seeds must exceed scaffold AND reference/context FaceNet by 0.005, gallery loss <=0.002, MAE/LPIPS regression <=1%, SSIM loss <=0.005, PSNR loss <=0.1dB. Missing-landmark error must decrease at least 5% versus scaffold and regress <=1% versus reference/context. At least 3/4 identities per seed must improve both FaceNet and structural error over scaffold. Beat both geometry ablations by 0.002 mean FaceNet with <=1% MAE/LPIPS regression. Require complete reconstructed-arm metrics/detections, exact preservation, and no material new structural/expression errors on every visual sheet. Nine primary paired identity-level contrasts (FaceNet, hole MAE, structural error versus scaffold, reference/context and wrong-person) use bootstrap intervals, exact sign flips and Holm correction. Four people cannot establish superiority. Failure rejects progression; better identity with worse fidelity is a trade-off. A pass only permits separately frozen independent confirmation, subject to further novelty review. No post-result threshold tuning.

## Numerical conventions fixed before the screen

Coordinates denote pixel centres. Anchor distance is Euclidean distance to missing pixel centres; component membership uses nearest pixel (floor(x+0.5)). All four bilinear destination neighbours must lie in the same four-connected missing component, including zero-weight neighbours at integer locations. The Laplacian diagonal stays four at mask/image boundaries. Both two-dimensional anchor point sets require singular-value ratio at least0.02. Sampling is OpenCV INTER_LINEAR with BORDER_REPLICATE; this is fixed interpolation, not a failure fallback. The Jacobian check uses NumPy finite differences at pixel centres and is not a mathematical guarantee of continuous bijectivity. Before each seed, an identical source/destination point at the first valid two-by-two mask interior tests byte-exact no-displacement operation; no suitable interior or failed equality is a shared technical failure. Reference extraction failures affect only arms actually using that reference. All ablation thresholds apply separately to both seeds, as do the baseline thresholds. No source, evaluator, gate or numerical setting may change after the frozen signature is written.
