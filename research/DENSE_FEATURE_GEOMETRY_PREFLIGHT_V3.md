# Dense CLIP geometry v3 — fixed feasibility protocol

11 October 2026, before execution. This tests existing frozen CLIP patch features, not DIFT, adapter training or reconstructed-image quality. No new assets downloaded.

Keep the eight original training cases, masks and four reference images; verify prior cache and source hashes. No development cases. Freeze the local ViT-H/14 CLIP image encoder. Resize each full square RGB image to 224 with the existing CLIPImageProcessor (no face detection/alignment). Sanitize missing RGB to 128 first. Use penultimate hidden states, discard CLS, retain the 16x16 grid and 1280-dimensional features; L2 normalize each patch. Target and reference coordinates remain the original 512-pixel grid-cell centres. Restrict centres to [48,464] on each axis; target patches must be >32 pixels from missing pixels. Self-attention has global context, but missing content is sanitized before encoding; these are not strictly local receptive fields.

Use mutual nearest-neighbour cosine matches. Require cosine >=0.6 and a >=0.02 margin over the second-best candidate in both directions. No parameter sweep. Sort matches by target coordinates and hold out every third pair. Apply the same fixed geometric gates as v2: >=12 matches, >=8 fit inliers, >=60% inliers, RANSAC 4px/2000 iterations/.99 confidence/seed20261011, validation RMS<=12px, fit spans>=100px on both axes, proper positive similarity scale[0.5,2]. Require at least two eligible references per case and all eight cases for positive coverage. This tests visible geometry only, not missing-eye correctness.

Negative control: pair each target with the four references of the next training identity in fixed manifest order, wrapping last to first. No extra feature extraction. Record all wrong-person matches and acceptance; >10% accepted wrong-person pairs fails the specificity gate. Different faces can share facial geometry, so rejection failure disqualifies this as a standalone reliability criterion, not as evidence that geometric matching itself is meaningless.

Unit tests first: synthetic known matches, no-match rejection, correspondence ordering and isolated geometric validation. Then check studio idle and >=4GB GPU free. Load only frozen CLIP fp16, batch1, inference_mode. Expected peak <3.5GB; measured allocated peak must stay <=3.5GB, with all finite features and zero trainable parameters. First training target is a bounded extraction probe. Verify features exactly invariant to altered RGB under the same mask by re-encoding that target. Abort on failure and preserve receipt. No optimizer/backward is used because this experiment has no trainable component. Record runtime, versions, device, model/source hashes and every failure.

Continue to the remaining training/reference encodings only after that probe passes. Matching and RANSAC run on CPU. Write only a new v3 directory; feature tensors stay local and are not GitHub artifacts. Do not modify prior protocols/results, baseline generator/evaluator, app or checkpoints. A passing diagnostic permits further eye-extrapolation validation, not immediate training or promotion. Failure must be diagnosed before a larger experiment; no score improvement is implied by coverage.
