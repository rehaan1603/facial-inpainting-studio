# Registered reference detail: fixed feasibility diagnostic

10 October 2026. Freeze before inference. The completed four guidance/appearance arms retain colour, gaze and eyebrow discrepancies. Global feature conditioning alone has not resolved spatial detail. Test one post-generation mechanism: registered real-reference eye/brow texture, with the CFG 3 result as a fixed scaffold.

Three fixed people (263, 6681, 10149), seed 17 and the same four real reference photos. No new generation, training, mask changes, target-derived descriptions or clean-target pixels. Landmark estimation uses the scaffold only for its detected bounding box; target landmarks are estimated on the damaged input with all missing pixels replaced by 128. Registration uses only observed anchors at least eight pixels from the original missing mask and image edge, minimum six nondegenerate anchors. Missing-eye landmark predictions never determine the registration fit. Existing frozen InsightFace 68-point model, CPU.

For each supplied reference, measure eye aperture from its six-point eye contours. Both eyes must have aperture ratio >=0.16. Fit a proper similarity transform on visible target anchors. Require RMS anchor residual / target bounding-box width <=0.06. Select the eligible reference with smallest residual; ties retain supplied order. This is a heuristic reliability filter, not a validated confidence estimator, and can miss makeup/hat occlusion. If none qualifies, retain the scaffold and disclose fallback.

Warp the selected photograph, including a validity mask, using only that fitted transform. Define two eye/brow support ellipses from the registered reference eye and brow landmarks, expanded 10 percent in width and height, feathered with Gaussian sigma 2 pixels. Apply inside the original damage mask only. Require at least 80 percent of each support ellipse to lie in valid masked pixels. Preserve the current reconstruction everywhere else. Match a bounded per-channel median offset (maximum +/-24 RGB levels) from at least 200 safely visible face-hull pixels. No hidden-target statistics. Transfer strength is fixed at 1.0 inside the feathered support; do not search weights or references by ground-truth score.

First verify strength ZERO returns byte-identical scaffold pixels. Save reference eligibility/errors, anchor coordinates, transforms, residuals, support maps, selected index, photometric offset, raw/final output, source/input/reference/model hashes and failures in a fresh folder. The raw output here means the post-transfer image, not a new diffusion generation. No website change, no claim that another photographed gaze equals the original hidden gaze, and no production promotion.

Score with the unchanged evaluator against BOTH CFG 3 and original CFG 5 controls. Report primary hole PSNR/SSIM, hole/eye contextual LPIPS, FaceNet, ArcFace and supplementary eye/brow metrics, with all per-person failures and fallbacks. Success requires SSIM gain without identity or perceptual deterioration on the same pairs and visibly improved eye detail. This is feasibility on observed development data; multiple seeds, corrupted references and unknown-client validation remain separate requirements.
