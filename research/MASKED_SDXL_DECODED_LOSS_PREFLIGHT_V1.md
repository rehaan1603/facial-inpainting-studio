## Audited path and hypothesis

The current nine-channel frozen SDXL UNet receives forward-noised clean target latents, a nearest-resized binary mask and unnoised masked-image latents. Four separate real-reference FaceID/appearance banks enter frozen projections and seventy modified attention processors. Only the shared bounded appearance-token compatibility scorer (10 -> 32 -> 1, 385 parameters) is learned. Its current objective is 0.25 full epsilon MSE + 0.75 normalized hole epsilon MSE. Neither decoded iris colour nor brow/gaze structure has direct image-space supervision. This is a plausible limitation, not a proven cause of every error; fixed appearance-branch strength and absent anatomical correspondence also remain limitations.

The installed Diffusers 0.40 AutoencoderKL.decode calls post_quant_conv and Decoder under apply_forward_hook, without a no_grad/inference decorator. The standalone VAE has no offload hook. Frozen weights still allow gradients with respect to its input. Decoder checkpointing tests torch.is_grad_enabled(), including in eval mode, and the library default uses non-reentrant checkpointing. Moving x0 to CPU with Tensor.to preserves autograd; detach, NumPy conversion of x0, PIL output conversion, inference_mode, sampling pipelines and Poisson finishing would sever the desired path and are prohibited. Pin installed decoder/model/checkpoint utility source files.

Hypothesis: a direct loss on decoded missing pixels can produce an additional finite gradient through the frozen decoder/UNet to the existing scorer. This probe tests that hypothesis and resource feasibility only. It cannot establish SSIM, identity, perceptual improvement or accurate hidden-eye recovery.

## Exact single intervention

- Use only original training identity **6792**, HQ target **28120**, the first retained v2 cache case and its existing four real references. The eight-person manifest and all cache/source/model pins must verify. Protected/evaluation identities 263, 6681, 7400 and 10149 are never opened. The one training target is EXIF-transposed, RGB and Lanczos-resized to 512 exactly as cache preparation; verify source hash immediately before decoding.
- Load the completed v2 **last** scorer checkpoint (SHA256 `0f6ad433ce03a998c4fe4375e309fe79a85bc0d945448774fb603edbeace84ba`). Copy into a new in-memory scorer; never overwrite a checkpoint. Positive text, four reference banks, FaceID 0.8 / appearance 0.2, chunk 64, architecture and frozen parameter count remain unchanged. Frozen fp16 UNet, bf16 CUDA autocast, fp32 scorer/loss, non-reentrant checkpointing and training-only Flash/Math backend policy are inherited.
- Use one conditional batch, 512 / latent 64, timestep **300**, CUDA float16 noise seed **20261011**, cached float16 clean/masked latents and the pinned DDPM epsilon scheduler. Let z_t be the actual scheduler.add_noise result and alpha_bar its cumulative alpha at 300. Compute in float32 `x0 = (z_t - sqrt(1-alpha_bar)*epsilon_prediction) / sqrt(alpha_bar)`. This is a single-step training estimate, not a sampled final reconstruction. Check the algebra against the same formula using known training noise, requiring finite maximum inverse residual at most **0.02** and recording both maximum and RMS; tolerance allows the inherited float16 add_noise rounding, rather than claiming an exact inverse.
- Load the same pinned SDXL VAE fp16 asset cast to **CPU float32**, eval, frozen; disable slicing/tiling, enable decoder gradient checkpointing and require no offload hooks. Decode `x0.to(cpu, float32) / 0.13025`. Its output is affine-converted to RGB by `decoded / 2 + 0.5`, **without clipping**, so out-of-range error retains gradients. This training penalty is distinct from clamped image export/evaluation.
- Reconstruct the existing 512 filled rectangular eye mask from its cached exclusive bbox, require exact cached binary SHA256 and nearest64 tensor equality, and normalize RGB L1 by **3 * full-resolution hole pixels**. No alternative region or resize is allowed. Define `L_rgb = sum(mask * abs(decoded_rgb - training_target_rgb)) / (3 * sum(mask))` and `L_total = 0.25 L_full_epsilon + 0.75 L_hole_epsilon + 0.1 L_rgb`. The coefficient **0.1** is fixed before the probe; it is a starting recipe, not an optimized value.
- Compute epsilon and unweighted RGB gradients separately with autograd.grad, record each norm and their cosine, then assign the exact sum `g_epsilon + 0.1*g_rgb` for one **disposable** AdamW update (lr 1e-4, weight decay 0.01, clip norm 1). No other loss, capacity, reference-selection, branch gate, inference setting or metric change is added. Separate gradients establish whether the new loss actually reaches the scorer; a combined nonzero gradient alone is insufficient.
