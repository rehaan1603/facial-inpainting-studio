# Masked SDXL compatibility: fixed real-data pilot v1

10 October 2026. Save and review this protocol, cache preparation and trainer before execution. Preserve every previous result, checkpoint, dataset and production default. This is a small development experiment, not a full-dataset result or an unknown-client accuracy measurement.

## Audit and justification

Use the [audited architecture](MASKED_SDXL_COMPATIBILITY_FEASIBILITY_PREFLIGHT_V1.md) and unchanged 385-parameter shared token scorer. The initial 1024 synthetic backward failed with an attention-kernel alignment error; the separately retained 1024 backend-recovery attempt was interrupted without final measurements. Neither demonstrates a memory limit. The bounded 512-equivalent attempt passed: neutral maximum difference zero, finite nonzero gradient, one disposable update, no frozen-weight gradients, and 7,289,674,752 allocated GPU bytes. This justifies testing 512 training, not a claim of improved images, 1024 training, or feasible decoded identity/perceptual losses.

Only the new appearance-attention logit bias is trained. SDXL UNet, FaceID Portrait and Plus Face projections/attention matrices are frozen (3,366,130,756 loaded parameters). Text, VAE, face analysis and CLIP vision are frozen CPU cache encoders. Ten target-query/reference-key statistics feed `Linear(10,32) -> SiLU -> Linear(32,1)`; final layer starts at zero; bias is bounded by `0.5*tanh`. Appearance contributions are zero outside the supplied query-hole mask; all four reference token sets retain joint normalization. Text and FaceID attention remain unchanged. Learned tokens do not encode anatomical correspondence. No additional capacity, branch gate, loss or reference-selection rule is introduced in this experiment.

## Frozen training data and schedule

Consume only the complete, hash-verified cache from [data preflight](MASKED_SDXL_COMPATIBILITY_DATA_PREFLIGHT_V1.md). Manifest SHA256 `f01f52bae44001bc9c23d36c0b4c5b48cd8e60e8f19cb1ba717be085143f117e`; identities in order: 8570, 6792, 4410, 2250, 3930, 8173, 2083, 7506, 4625, 38, 4164, 674, 8660, 476, 1281, 8748. Adapter holdouts 263, 6681, 7400 and 10149 are excluded. Disjointness applies to this adapter, not pretrained/earlier project exposure.

Train at 512 pixels (latent 64x64), batch one, **64 fixed updates**: four rounds of all 16 identities in manifest order, with timestep 100, 300, 500 and 700 respectively. Seed 20261010 initializes the scorer. Noise for update index i (zero-based) is a fresh CUDA generator with seed 20261010+i+1. No shuffle, augmentation, validation-based stopping or best-checkpoint selection. Exactly the last update is evaluated.

Use `DDPMScheduler.from_config` of the pinned SDXL scheduler, preserving its scaled-linear betas, 1,000 timesteps and epsilon prediction. Forward noise clean cached latent using the scheduler's `add_noise`: `z_t=sqrt(alpha_bar_t)*z_clean+sqrt(1-alpha_bar_t)*epsilon`. The nine-channel input is `[z_t(4), binary latent mask(1), cached masked-image latent(4)]`; only the clean latent is noised. Use positive prompt/pooled text/time IDs and the four positive FaceID/CLIP feature banks; no classifier-free training branch or dropout. Supplied hole and visible fraction are per-example conditioning and remain fixed through backward/checkpoint recomputation.

Objective: `0.25*mean((epsilon_pred-epsilon)^2) + 0.75*sum(hole*(epsilon_pred-epsilon)^2)/(4*sum(hole))`. This is explicit hole-weighted latent denoising supervision, not image-space SSIM, RGB, LPIPS or identity training. Keep the module/loss distinction clear. Identity is guarded by evaluation; no identity-loss benefit is claimed. Reconstruction geometry may improve, regress or remain unchanged.

AdamW learning rate 1e-4, betas (0.9,0.999), epsilon 1e-8, weight decay 0.01, no scheduler; clip shared-scorer gradient norm at 1.0 after recording its unclipped norm. Frozen weights float16; CUDA bfloat16 autocast; scorer and losses float32. Non-reentrant UNet and scorer-chunk checkpointing, query chunks 64. During training only, use Flash/Math SDPA (exclude the two backends implicated by the failed probe); restore flags on context exit. No overclocking or power-limit changes.

Before the first update compare a real conditional no-gradient prediction of the neutral scorer to the original local-appearance processor, maximum absolute tolerance 1e-3, finite values required. Require exactly 385 unique trainable parameters, 70 modified processors, all scorer gradients present and finite on each update, aggregate norm strictly positive, and no frozen-weight gradient. Initial first-layer gradients can be zero because the final layer starts at zero. Save scalar traces and preserve any failure. If this real-data graph fails, do not change masks, resolution, precision or loss in place.

Create only fresh `outputs/masked_sdxl_compatibility_pilot_v1/training/`: config, initial and last float32 scorer state dictionaries, trace and receipt.
