# Masked SDXL compatibility: architecture audit and feasibility plan

10 October 2026. Preserve the existing studio, controls, datasets, checkpoints and every experimental result. This is a **synthetic gradient/memory probe**, not dataset training, a new reconstruction result or proof of quality improvement. Complete the audit and inspect the proposed implementation before running it. Any later training needs its own frozen data/loss/schedule protocol.

## What the audit establishes

The three-person erased-eye study uses [SDXL + FaceID Portrait](../scripts/reference_inpaint.py), not the earlier [ReF-LDM compatibility trainer](../scripts/train_target_compatibility_v1.py). The latter's shared `Linear(10,16) → SiLU → Linear(16,1)` has **193 parameters** and modifies 16 ReF-LDM `QKVAttentionLegacy` layers. It is not loaded into the SDXL path. Training it again cannot change the current masked SDXL results.

The stored nine-channel SDXL UNet has **2,567,478,084 tensor elements across 1,680 tensors**, counted from the pinned safetensors header. This bare-backbone count excludes the subsequently installed IP-Adapter projection and attention weights; the probe must enumerate the complete loaded frozen model separately. Current inference optimizes **zero parameters**. UNet, VAE, text encoders, FaceID/appearance projections and attention matrices, and recognition encoders remain pretrained/frozen. Frozen weights still require downstream activations to carry gradients to an inserted module.

The mask reaches SDXL through `[noisy latent (4), hole mask (1), masked-image latent (4)]`. Text/pooled text and time IDs provide the remaining conditioning. Four reference FaceID embeddings each produce 16 learned tokens, 64 total. The optional Plus Face branch resamples each reference's 257 CLIP features into another 16 learned tokens. These are semantic learned tokens, not known eye/iris coordinates or pixel correspondence. Global identity conditioning consequently does not ensure the hidden target's eye colour, gaze, expression or eyebrow size is recovered.

The installed `StableDiffusionXLInpaintPipeline.__call__` is decorated with `torch.no_grad()`. Calling [reconstruct()](../scripts/reference_inpaint.py) inside a training loop would produce no adapter gradient. A trainer must call the UNet directly, with valid nine-channel inputs and conditioning. OpenCV/Poisson finishing is nondifferentiable. Any later decoded reconstruction, perceptual or identity objective must operate on differentiable VAE output and mask composition **before** finishing; final quality evaluation continues to use the existing finishing protocol.

Previous masked studies are inference interventions, with no masked SDXL training losses. Earlier ReF-LDM training used full/face-ROI latent epsilon MSE and separate decoded identity variants; those losses must not be described as training this model. FreeU, additional visual appearance, local appearance routing, registered texture and 50 denoising steps retain failures/trade-offs. [Latest numeric evidence](focused_eye_ssim_studies_v1_verification.json) covers 13 GPU calls, not training updates.

The existing masked evaluator remains frozen: RGB hole PSNR; Gaussian SSIM over fully contained 11×11 windows; AlexNet LPIPS on fixed contextual hole/eye crops; separately detected FaceNet and conditioning-family ArcFace; explicit null detector failures. Whole-image SSIM is dominated by preserved pixels. Three repeatedly examined development identities are not unseen-client performance evidence. Tiny anatomical eye-window counts remain supplementary diagnostics, not replacement primary scores.

## Recommended single intervention

Test **bounded learned target-query/reference-token compatibility in the existing appearance attention branch**, localized by the supplied hole mask. Keep FaceID, text, original attention/projection weights and all four references frozen. Retain joint normalization across reference tokens. A shared `Linear(10,32) → SiLU → Linear(32,1)` scorer has exactly **385 unique trainable parameters**. Zero-initialize the final layer; bound its attention-logit bias by `0.5 × tanh(score)`. This is a token-compatibility proposal, not anatomical correspondence or a claim of novelty.

Use ten explicitly recorded statistics of target-query/reference-key representations, timestep and supplied-mask coverage. Define their ordering/formula in the helper and receipt before execution. Retain the query/key feature gradient graph. The fixed feature order is: unit-vector cosine; normalized RMS difference `sqrt((2−2cos)/head_dim)`; absolute unit-vector channel-mean difference; absolute unit-vector channel-standard-deviation difference; log1p query norm; log1p key norm; log1p absolute norm difference; key cosine to the normalized mean of all appearance keys; timestep/999; global visible-target fraction from the supplied mask. These partly correlated scalar statistics do not establish spatial alignment. Avoid expanded query×key×channel differences; chunk/checkpoint the small scorer to control memory. No clean photo, anatomical evaluation annotation, synthetic target-derived reference or reference-corruption oracle enters the probe or later inference. During training, zero initialization must retain the gradient path; do not bypass the module merely because its initial bias is zero. Initially the first layer has zero gradients while the final weight must have a nonzero aggregate gradient; all parameter gradients must be present and finite. A shared uniform offset has no effective attention gradient at neutral initialization; the registered parameter count does not imply independent useful degrees of freedom.

Compare with the **same local-appearance architecture without bias** for neutral equivalence. Original appearance-OFF CFG3 remains the required eventual quality control. Do not mistake improvements against the weaker appearance architecture for improvements against current CFG3. Neither a lower synthetic loss nor a successful backward pass demonstrates reconstruction improvement.

## Synthetic probe contract and stopping rules

- New code: `scripts/sdxl_token_compatibility_probe_v1.py` and a small CPU attention-contract test. Original generator/scorer and installed libraries stay unchanged.
- Fresh output receipt; refuse overwrite. Record this protocol and script hashes, model/adapter asset pins, installed source/version hashes, architecture and exact unique frozen/trainable counts, random seed, synthetic tensor shapes, loss, gradient norm, update status, runtime and peak allocated/reserved GPU memory.
- One conditional batch, four synthetic reference embeddings/feature banks, synthetic prompt/pooled text, correctly shaped time IDs, random input/target tensors and a fixed hole mask. This intentionally excludes actual image encoders, realistic latent distribution/noising schedule, VAE, FaceNet/LPIPS losses, multi-step denoising and optimizer history. Random tensors establish a graph/memory contract only; a real trainer must obtain clean latents and use the pinned scheduler's forward noising equation. Those require separate feasibility checks.
- First probe: **1024-pixel equivalent**, latent 128×128, fixed timestep 500, seed 20261010; normalized hole-weighted epsilon MSE (0.25 full + 0.75 hole). Frozen weights fp16, bfloat16 autocast, shared scorer float32, non-reentrant UNet/scorer checkpointing. No inference CPU-offload assumptions for backward.
- Compare neutral direct-UNet predictions to the same local architecture: maximum absolute tolerance **1e-3** in the mixed-precision probe and **1e-5** in tiny float32 CPU tests. This is numerical equivalence, not byte-exact inference reproduction.
- Require all adapter gradients present/finite, a nonzero aggregate gradient and a real temporary parameter update; no gradients on frozen weights. Discard the temporary update. Save no candidate/model checkpoint.
- Preserve any OOM or other failure in a receipt. Do not silently resize or change precision. If 1024 fails, a **separate 512-equivalent receipt** may measure a lower-resolution training configuration; it is not a successful 1024 probe or a changed final evaluation.
- Run serially only while the studio is idle. Keep the current local website and all prior defaults. Do not overclock or modify power limits.
